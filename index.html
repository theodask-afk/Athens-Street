SYNC SETUP

Sync notes across devices

Your notes always save on this device first. To also see them on your other phones or tablets, connect a free Firebase project (Google's app backend — the free plan needs no credit card) and pick a private sync code to enter on each device.

  1. Go to the Firebase Console and create a project
  2. Build → Firestore Database → Create database (production mode, any region)
  3. Build → Authentication → Sign-in method → enable Anonymous
  4. Project settings → General → "Your apps" → add a Web app → copy the firebaseConfig object shown

GOODBYE

Ready to close?

Mobile browsers don't let a web page close itself — that's a security rule Chrome and Safari both enforce for every site, not something specific to this app.

To fully exit, open your phone's recent apps (swipe up and hold, or tap the recents/square button) and swipe Athens Street Names away, the same way you'd close any other app.
